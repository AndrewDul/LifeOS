# LifeOS

A local-first personal life operating system. Tauri 2 + React + TypeScript + Rust.

See `CLAUDE.md` for operating rules, `docs/LIFEOS_SPEC.md` for the product
and architecture specification, `docs/RESEARCH_DECISIONS.md` for research
and technology decisions, and `docs/PROJECT_STATE.md` for current
engineering status.

## Development

```
npm install
npm run tauri dev
```

Requires Rust (`rustup`) and, on Windows, the Visual Studio "Desktop
development with C++" workload. See `docs/PROJECT_STATE.md` for the
current prerequisite status on the reference dev machine.
